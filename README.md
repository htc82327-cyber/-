# Пей воду — Android V1

Первая нативная Android-версия проекта «Пей воду».

## Что уже есть

- Нативный интерфейс Jetpack Compose.
- Два режима: «Упрощённый» и «Полный».
- Онбординг: имя, возраст, пол, рост, вес, стакан, режим и голос.
- Грамматика кнопки по полу: «Я выпил стакан» / «Я выпила стакан».
- Анимированный стакан с заполнением водой.
- 10-секундная защита от повторного нажатия.
- Учёт стаканов или миллилитров.
- Редактируемая ориентировочная дневная цель.
- Пять бесплатных офлайн-материалов.
- PLUS можно включить локально в тестовом режиме: 1 месяц / 6 месяцев / 1 год.
- При PLUS появляется расширенная библиотека и недельная статистика.
- Спокойный голос встроен в `res/raw` (10 WAV-файлов).
- Энергичный голос V1 — временная ускоренная версия того же локального аудио.
- Локальные напоминания через WorkManager, без интернета.
- Системное уведомление создаётся без стандартного звука и вибрации.
- Голосовая фраза воспроизводится отдельно и может быть выключена в настройках.
- Тест тихого уведомления из настроек.
- Выбор интервала: 60 / 90 / 120 / 180 минут.
- Напоминания выполняются только примерно с 08:00 до 22:00.
- Выбор фото стакана в онбординге. Оценка объёма пока демонстрационная, без API.
- Нижняя панель сделана в стеклянном стиле.
- Никаких эмодзи в интерфейсе.
- Android-версия сохраняет профиль и прогресс локально. Запрет на сохранение относился только к HTML-макету.

## Что пока специально не подключено

- Реальные платежи Google Play.
- Реальная серверная активация PLUS / Cloudflare / генератор ключей.
- ИИ-распознавание объёма стакана по фотографии.
- Отдельные аудиофайлы для PLUS-голосов.
- Точное будильниковое расписание до минуты: WorkManager может сдвигать фоновый запуск системой Android.

## Сборка APK через GitHub

В проекте уже есть `.github/workflows/android.yml`.

1. Создать пустой GitHub-репозиторий.
2. Загрузить в него **содержимое** этой папки.
3. Открыть вкладку **Actions**.
4. Запустить `Build Android APK` либо сделать push в `main`.
5. После сборки скачать artifact `PeyVodu-debug-apk`.

APK внутри artifact: `app-debug.apk`.

## Android Studio

Проект использует:

- Android Gradle Plugin 8.7.3
- Gradle 8.9
- Kotlin 2.0.21
- compileSdk / targetSdk 35
- minSdk 26
- Jetpack Compose + Material 3

Если Android Studio попросит создать/обновить Gradle wrapper, можно согласиться. GitHub Actions wrapper не требует, потому что Gradle 8.9 устанавливается отдельным action.

## Голоса

Файлы `calm_01.wav` ... `calm_10.wav` лежат в:

`app/src/main/res/raw/`

Первые пять используются для фоновых напоминаний. Остальные используются как ответы после записи воды и достижения дневной цели.
